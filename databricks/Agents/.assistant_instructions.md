## Agent Memories

### Project: Mizuki Airflows (ANAC Aviation Data Pipeline)

**Data architecture:** Bronze → Silver → Gold (medallion architecture)
- **Bronze**: Raw CSV data from ANAC (vra, aerodromos_publicos, empresas_aereas_nacionais, empresas_aereas_estrangeiras)
- **Silver**: Governed mirror of Bronze (same row counts, typed columns, COMMENT on all columns, tags). No business filters allowed.
- **Gold**: Star Schema dimensional model for aviation analytics

**Silver rule (non-negotiable):** Silver is an exact mirror of Bronze — same table names, same grain, same row count. No business filters, no aggregations. Headers from Bronze are kept in Silver.

**Gold Star Schema:**
- `dim_tempo` (366 days, 2025-08 to 2026-08)
- `dim_empresa` (169 unique airlines by ICAO, deduplicated)
- `dim_aerodromo` (496 public aerodromes with decimal coordinates)
- `dim_tipo_linha` (4 types: N=Nacional, I=Internacional, G=Geral, C=Cargueiro)
- `dim_situacao_voo` (2: REALIZADO, CANCELADO)
- `dim_rota` (3,104 routes with haversine distance in km)
- `fato_voos` (1,014,705 flights, partitioned by data_partida_prevista)
- `auditoria_carga` (load metrics)
- `vw_otp_por_empresa` (On-Time Performance view)
- `obt_voos` (One Big Table: fato denormalizada with all 7 dims, 1,014,705 rows, partitioned by data_partida_prevista, prefix conventions: empresa_, origem_, destino_, rota_)

**Key metrics:** OTP threshold = 15 min (ANAC/IATA standard). 79.9% on-time departure. 97.1% realized, 2.9% cancelled.

**Catalog:** mizukiairflows (schemas: bronze, silver, gold)

**Notebooks:**
- Silver: Silver - Camada Governada (id: 532588949851061)
- Gold: Gold - Camada Analitica (id: 1868996407835791)
- DQ Assessment: Avaliação Qualidade Aerodromos (id: 717891997200939)

**Compute:** Serverless (CPU). Materialized views not supported — use regular views instead.

### Dashboard: Operações de Voos — OBT (id: 01f1b368b4341a16ab981aba5d8987fe)

**Dashboard ID:** 01f1b368b4341a16ab981aba5d8987fe
**Page:** pages/13e0c9aa ("Operações de Voos")

**Dataset:** datasets/obt_voos ("OBT Voos") — SQL: SELECT * FROM mizukiairflows.gold.obt_voos

**Calculated fields (editDatasetCalculations):**
- total_voos (measure): COUNT(*)
- voos_realizados (measure): SUM(CASE WHEN `flag_realizado` THEN 1 ELSE 0 END)
- voos_cancelados (measure): SUM(CASE WHEN `flag_cancelado` THEN 1 ELSE 0 END)
- taxa_pontualidade (measure): ROUND(100.0 * SUM(CASE WHEN `partida_pontual` THEN 1 ELSE 0 END) / NULLIF(SUM(CASE WHEN `flag_realizado` THEN 1 ELSE 0 END), 0), 1)
- serie (dimension): CASE WHEN `flag_realizado` THEN 'Realizados' WHEN `flag_cancelado` THEN 'Cancelados' ELSE 'Outros' END

**IMPORTANT:** SQL dataset widget queries silently DROP complex expressions (SUM(CASE WHEN...), ROUND(...), CASE WHEN...). Use editDatasetCalculations to define them as calculated fields, then reference with MEASURE() in editWidgetsV2 queries.

**12 widgets:** text header, 4 KPI counters (total/realizados/cancelados-red/OTP-green), line chart (monthly evolucao), pie (tipo_linha), bar (top empresas), bar (situacao), bar (faixa distancia), symbol map (aerodromos), table (resumo empresa)
